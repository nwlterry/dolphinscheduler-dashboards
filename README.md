# dolphinscheduler-dashboards

Kibana saved-object exports for DolphinScheduler / Whaleops monitoring.

## Layout

```
dashboards/whaleops_monitoring.ndjson
dashboards/whaleops_monitoring.json
dashboards/dolphinscheduler-alert.ndjson
GROUP.md
README.md
```

Import NDJSON in Kibana: **Stack Management → Saved Objects → Import**. Poller: [elasticsearch-http-json](https://github.com/nwlterry/elasticsearch-http-json).
